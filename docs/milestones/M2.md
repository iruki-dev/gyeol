# M2 — Data

## Delivered

- **Adapters** (`gyeol.data.adapters`). Each one scans a local tree into a license-tagged `Manifest`, never downloads
  anything, and reports every file it skips, with the reason.
  - `scan_vocalset`: singer, context, technique and vowel from path components. VocalSet techniques are mapped onto
    gyeol's phonation labels (belt → `pressed_belt`, breathy, vocal fry → `fry`, vibrato / straight).
  - `scan_aihub`:
    - Handles #465 and #473.
    - Audio is paired with its same-stem JSON label file.
    - Prints the AI Hub conditions (no redistribution, domestic processing, individual download).
    - The label schema is **not assumed**: fields come from an explicit `AIHubFieldMap`, and `inspect_json_keys`
      discovers the schema of downloaded files. The default map is a placeholder, and unmapped files are reported,
      not guessed.
  - `scan_gtsinger`:
    - Pairs `Control_Group` (technique off) with `<Technique>_Group` (technique on) by song and file stem.
    - The license gate refuses it under the commercial profile (research only).
  - `scan_own`: in-house recordings from `recordings.json`. Only owners who currently consent to `training` are
    included (the check comes from `ConsentStore.allows`). The `own_recordings` asset is registered as
    `commercial_ok` with that condition.
- **Splits** (`gyeol.data.splits`): seeded, hash-based, singer-disjoint splits (train / calib / test) that stay
  stable as data grows, plus `pairs()`.
- **Augmentation** (`gyeol.data.augment`). Each transform returns `(audio, labels)`, and `env_classes()` maps the
  labels to class ids for the M4 env heads.
  - noise: white, pink or babble, at an SNR;
  - reverb: synthetic T60/DRR, or measured RIRs;
  - device EQ: high-pass corner, low-pass, tilt and peaks;
  - codec: ffmpeg mp3/aac/opus, or a simulated codec (band limit plus spectral quantisation);
  - compression and AGC;
  - separation artefacts: mask musical noise, spectral holes and optional residual accompaniment;
  - Bluetooth jitter: route latency, wandering delay and packet loss;
  - `timbre_shift`: true-envelope formant warp with f0 kept;
  - `pitch_shift`: phase vocoder plus resampling, with formants restored.
  `AugmentationPipeline` is deterministic given a seed.
- **Paired loader** (`gyeol.data.paired.PairedLoader`): it loads license-gated (off, on) pairs, analyses both with the
  signal layer, and aligns *on* to *off* with the content-only warp. The band is widened to cover the length
  difference. The f0 and loudness curves come along so they can be regressed out in M7.

## Verified (tests, synthetic data)

| Check | Result |
|---|---|
| Pitch shift | exact f0 (±1 %) and formants kept within 5 % |
| Timbre warp α = 0.85 / 1.15 | formants move by ×0.80–0.95 / ×1.05–1.20, with f0 unchanged |
| Reverb augmentation | measurable by the T60 estimator |
| Simulated codec | lowers the measured bandwidth |
| Bluetooth delay | recovered exactly; wander stays within its bound |
| Paired loader | aligns a take shifted by 150 ms to within 40 ms |
| Commercial profile | GTSinger refused; own recordings without training consent excluded |

## Not done / to verify with real data

- AI Hub and GTSinger on-disk schemas must be checked against the downloaded datasets. The adapters take explicit
  mappings for exactly this reason.
- Timbre warping at high f0 (> 300 Hz) is only as good as the true envelope there.
- No measured RIR or device-response collections are bundled. The augmenters accept them as arrays.

## Example

```python
from gyeol.data import scan_vocalset, open_manifest, singer_split
from gyeol.data.augment import AugmentationPipeline
from gyeol.core import Profile

report = scan_vocalset("/data/VocalSet")
ds = open_manifest(report.unwrap().manifest, Profile.COMMERCIAL)
splits = singer_split(ds.manifest)
y, labels = AugmentationPipeline(seed=0)(audio, 44100)
```
