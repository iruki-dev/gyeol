# M1 — Signal layer (no training)

## Delivered

| Area | Module | What it does |
|---|---|---|
| IO | `io.audio`, `io.loudness` | Raw loading with an explicit status, polyphase resampling, BS.1770-4 integrated loudness and normalisation (−23.01 LUFS reference tone verified), A-weighting |
| Latency | `io.latency` | Loopback chirp calibration (PHAT cross-correlation), tap-along calibration with jitter, and offline onset-envelope refinement against the guide vocal |
| Frontend | `frontend.quality` | Clipping on **raw** input, SNR against a minimum-statistics floor, effective channel bandwidth plus codec-cliff detection, backing-track bleed (null-referenced coherence), and a per-frame confidence factor |
| Environment | `frontend.env` | T60 from free decays with an explicit `UNRELIABLE` status; DRR returns `UNAVAILABLE` until M4 |
| Separation | `frontend.separation` | License-gated `CallableSeparator` (RoFormer), `DemucsSeparator`, `BackingTrackCanceller` and stem agreement |
| Pitch | `pitch` | `PitchTracker` protocol. DSP pYIN/YIN/SHS trackers. SwiftF0 and FCPE adapters, optional and license-checked. RMVPE raises `NotImplementedError` (TODO M8). Octave-aware consensus: each tracker's estimate ×{½, 1, 2}, a harmonic salience test, odd/even and half-integer octave tests, and Viterbi continuity |
| Curves | `attributes` | `f0_cents`, `voicing`, `subharmonic_ratio`, `loudness`, `loudness_rel`, `periodic_db`, `aperiodic_db`, `aperiodic_ratio`, `pitch_center`, `vibrato_rate`, `vibrato_extent`, `content` — each with per-frame confidence, lowered by quality flags |
| Events | `attributes.pitch_curves` | `scoop`, `fall`, `kkeokki` (꺾기) and `glide`, from f0 slope and shape in note context |
| Alignment | `align` | Banded DTW on content features only (liftered MFCCs plus log-energy in M1). Smoothing-spline projection, slope bounds, monotone τ. Confidence = match contrast within the band. Rhythm: onset deviations and tempo ratio |
| Explanation | `explain` | Octave-invariant (optionally semitone) Δ for intonation, global offset, interval compression, vibrato extent/rate, onset timing, tempo and ornament events. Take consistency (style/habit vs error) and "cannot judge" spans |
| Text | `explain.render_text`, `resources/ko/explain.json` | Korean strings live in resource files, with particle agreement (이/가 …) |
| Weak labels | `dsp.weak_labels` | Gated v0.1 formants, H1*–H2* and CPPS for M3 |
| Synth | `synth` | `melody()` with vowels, consonants, vibrato, scoops, falls, 꺾기, glides and timing shifts, with exact truth |

## v0.1 defects (regression tests in `tests/test_v01_regressions.py`)

1. **Bandwidth fooled by consonants, breath and reverb.** Bandwidth is now estimated over all active frames against
   a minimum-statistics floor. Breath and reverb give > 10 kHz instead of ~1 kHz.
2. **One octave error collapsed pitch confidence.** Consensus is now octave-folded: confidence stays > 0.7 and f0 is
   correct.
3. **High-f0 F1 mis-tracking inflated H1*–H2*.** A formant now needs F_n ≥ 2·f0, plus the F1-near-harmonic gate.
   Close vowels become invalid instead of inflated.
4. **Clipping measured after the high-pass.** It is now measured on the raw input: 39 % detected where v0.1 saw 0 %.
5. **T60 failed silently under noise.** It now returns `UNRELIABLE` with a reason. Clean estimates carry a documented
   +15–30 % bias.
6. **Rasp voice tracked an octave low.** The odd/even harmonic test now tracks the nominal pitch, and roughness is
   reported as `subharmonic_ratio`.
7. **Formants swapped under noise.** Several LPC orders must now agree and SNR must be ≥ 30 dB; otherwise the formant
   is missing.
8. **Synth correction poles near Nyquist.** The correction is now an analog-matched FIR. There are no digital poles
   within 1 kHz of Nyquist, and the response is identical at 16, 44.1 and 48 kHz.

## Measured on synthetic data (tests)

| Measure | Result |
|---|---|
| f0, 70–1000 Hz with vibrato | median error < 5 cents |
| Onset recovery (user an octave lower, with added vibrato and scoops) | within ±15 ms |
| Injected knobs, all recovered | intonation ±40 / +30 cents, onsets +60 / −50 ms, missing scoop, missing vibrato, octave transposition |
| Two takes | a consistent flat note is labelled `style_or_habit`; a late entry in one take only is labelled `error` |

## Not done / deviations

- `examples/coach_demo_v2.py` runs end to end on synthetic WAV files. **It has not been run on real singing
  recordings**, because none were available in this environment. The file path is the same code.
- Content features are a DSP stand-in (MFCC). The same vowel sung an octave apart costs more, which is handled by
  contrast-based confidence. M3's phonetic posteriors replace it.
- Soft-DTW refinement (optional in the brief) is not implemented.
- Audibility scores (M5), coaching policy and prioritisation (M6): the demo uses an explicit *demo-only* display filter
  (`examples/demo_display.json`), not coaching thresholds.
- Blind DRR/C50 are unavailable until the M4 env encoder.
