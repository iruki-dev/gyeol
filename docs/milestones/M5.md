# M5 — Full explanation and demo

## Delivered

- **Δc for every attribute** (`gyeol.explain.attributes`), all on aligned frames where both sides are confident:
  - **phonation**:
    - breathiness per note, from the aperiodic-to-periodic ratio (signal layer, always available);
    - register and phonation-quality items when learned heads (M3) produced posteriors on both sides. Register
      items carry `tentative: True` and the Korean wording is hedged ("…수 있어요").
  - **dynamics**: per-note loudness Δ and the phrase dynamic range (10th–90th percentile).
  - **diction**: phrase level only, compared with the **target singer's realisation** (their laryngeal and phone
    posteriors), never with a dictionary.
- **Take consistency** (from M1) now covers all items.
- **Remainder**: frames whose residual `r` differs far more than usual (robust z > 4) become "cannot judge" with
  reason `remainder`. Other reasons are `low_confidence` and `item_confidence:<attribute>`, each with its own Korean
  string.
- **Edits** (`gyeol.demo.edits`): each item maps to an edit of the **user's** c(t):
  - f0 in cents, gain in dB, aperiodic ratio in dB, a time map, or a learned-curve delta;
  - pitch ornaments are transplanted from the target, measured against the note centre;
  - edits scale (partial steps) and add (several items).
- **Feasible range** (`gyeol.demo.feasible`): from onboarding (`from_onboarding`, for M6) or the user's own takes.
  Edits are clipped to the range and the clipped fraction is reported.
- **Renderers** (`gyeol.demo.renderers`):
  - `DSPRenderer`: harmonic-plus-noise resynthesis of the user's own recording (`gyeol.demo.hnm`). Harmonic
    amplitudes are read from a peak envelope at the new harmonic frequencies, so formants stay put. Noise is seeded
    per frame, so a partial render equals the full one.
  - `NeuralRenderer`: the M4 decoder with the consented singer vector and a neutral env.
  - Both check the `ConsentedVoice` **and** that the take's recording is a USER recording owned by that voice's
    user and was the source of the representation (`UserTake`). A reference or target recording cannot be wrapped
    as a take, and its vector cannot become a voice.
- **Stepwise demos** (`render_demo`):
  1. an unedited baseline render (same renderer, for fair A/B);
  2. the selected item alone;
  3. partial steps (50 %, 100 %) of all other confident, renderable items toward the target style.
- **AI labelling**:
  - Every output is a `LabelledAudio`: watermarked through the pluggable `WatermarkHook`, with metadata
    (AI-generated notice in Korean and English, generator, renderer, consent token id, hashed user id, edits).
  - `save_labelled` writes WAV INFO tags plus a `.ai.json` sidecar; `read_label` reads either.
  - The default watermark is a documented spread-spectrum mark at −26 dB re the in-band level, with a z-score
    detector.
- **Audibility** (`gyeol.explain.audibility.score_audibility`):
  - For each item: render with only that item corrected and clamped, then compare with the unedited render over the
    frames the edit touches.
  - Metric: relative specific-loudness distance (80 mel bands, exponent 0.23).
  - Items the renderer cannot correct keep `audibility=None` with a reason.

## Verified (tests, synthetic singing)

| Check | Result |
|---|---|
| HNM resynthesis | f0 median error < 2 cents, level within 2 dB; +100-cent edit re-analyses at 100 ± 5 cents; gain exact |
| Single-item correction | a −50-cent note re-analyses at < 6 cents; the other notes' pitch and onsets are unchanged |
| Onset retiming | +70 ms onset re-analyses at < 25 ms |
| Ornament transplant | missing vibrato: rendered contour correlates > 0.9 with the target's, extent ratio 0.7–1.3; missing scoop is no longer "missing" |
| Consent gating | bare singer vector, `None`, reference recording, another user's take, revoked or analysis-only token: all raise |
| Feasible range | edits beyond the range are clipped and reported; in-range edits untouched |
| Stepwise demo | distance to baseline grows step by step; every output is labelled and its watermark detected |
| Watermark | detected after gain and 16-bit quantisation; not detected on clean audio or with another key; SNR > 30 dB |
| Audibility | −50 cents > +20 cents > ≈0 cents; a 70 ms onset error > a ≈0 ms one |
| Learned items | synthetic register, quality and laryngeal posteriors produce tentative register, quality and phrase-level diction items with Korean text |

## Known limitations (not hidden)

- **Audibility is uncalibrated.** A frame-wise spectral distance over-weights timing edits: a 0.2 % tempo
  correction scores like a 1 dB level change. Use it for ranking only; calibrating it against a listening test is
  M8.
- **Breathiness is confounded with vibrato.** In the signal layer, the harmonic/noise split (64 ms window) reads
  deep vibrato as extra aperiodicity: a note with target vibrato and a straight user tone shows as "less breathy".
  Learned phonation heads (M3, once trained) are the intended fix; until then the coach (M6) should down-weight
  breathiness items on notes with a vibrato difference.
- **DSP renderer quality.**
  - Plosive bursts are smeared into frame-length noise.
  - f0 edits cannot voice frames the user left unvoiced (e.g. the start of a transplanted scoop).
  - Aperiodicity edits re-analyse at roughly half their nominal dB, because of a harmonic-modulation noise floor.
- **Neural renderer**: the wiring is tested with a tiny random model; the output is noise until the M4 weights are
  trained. Edits of learned posteriors (register, phonation, diction) need a decoder conditioned on those curves.
  None exists yet, so those items report UNAVAILABLE in demos and audibility.
- **Consent for audibility**: audibility renders the user's voice, so it needs `voice_synthesis` consent. Without
  it, items keep `audibility=None` and the coach must rank by confidence alone.
- **Watermark**: the default mark does not survive time shifts that break block alignment, resampling, pitch
  shifting or lossy codecs. Its inaudibility has not been verified by listening. Replace it through the hook for
  production.
- Still no real singing data: every number above is from synthetic melodies.
