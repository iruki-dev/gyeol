# M4 — Autoencoder

## Delivered

- **`LogMel`** is aligned to the `FrameGrid`: `1 + N // hop` frames centred on `i·hop`, so mel, curves and r share
  one axis.
- **Encoders** (`gyeol.encoders.latent`):
  - `SingerEncoder`: attentive-statistics pooling and a same-singer supervised-contrastive loss. `singer_vector()`
    wraps the output in a `SingerVector` that inherits the source recording's provenance, so a reference vector can
    never become a `ConsentedVoice`.
  - `EnvEncoder`: an env vector plus supervised heads for the augmentation classes (noise, room, EQ, codec,
    compression, separation).
  - `ResidualEncoder`: a narrow frame-level VIB bottleneck.
  - `LeakageHeads`: adversaries behind gradient reversal that try to read f0, aperiodicity, loudness, singer id and
    env classes from r. A second set tries to read the env classes from the singer vector.
- **`AcousticModel`**:
  - A conv-transformer taking (singer, env, c(t), r(t), f0, aperiodic) and producing mel plus an aperiodicity stream
    (dB ≤ 0).
  - **Condition dropout**: dropped or unknown attributes are replaced by a learned "missing" embedding.
- **`NSFVocoder`**, reimplemented here; its weights are to be self-trained:
  - an f0-driven harmonic source (harmonics above Nyquist removed);
  - a subharmonic and jitter branch gated by a per-frame `rough` control;
  - source injection at every upsampling stage;
  - an aperiodicity-shaped noise branch.
  `BigVGANAdapter` is an optional fallback without f0 control, and loading its weights is license-gated.
- **Losses** (`gyeol.train.losses`):
  - multi-resolution STFT and mel L1, with **extra weight on consonant and low-energy frames** (`frame_weights`);
  - multi-period and multi-scale discriminators, LSGAN losses and feature matching.
- **Training step** (`gyeol.train.autoencoder.generator_step`) combines:
  - mel, STFT and KL losses;
  - env supervision;
  - SupCon over singers (only when the batch contains a same-singer pair);
  - leakage adversaries;
  - differentiable **re-encoding consistency on r**;
  - the adversarial losses.
  `batch_from_representations` builds batches from signal-layer representations, and the residual encoder's input
  may be a timbre-shifted copy.
- **Evaluation** (`gyeol.eval.reconstruction`):
  - `vocoder_benchmark`: log-spectral distance on voiced vs consonant frames, f0 RMSE and voicing error from
    re-analysis, and aperiodic-ratio error, all **per technique**.
  - `reencoding_consistency`: compares c(decode(x)) with c(x).
  - A listening-test protocol template is in `docs/protocols/listening_test.md`.

## Verified (tests, tiny CPU models)

| Check | Result |
|---|---|
| Harmonic source | every strong spectral peak is a harmonic of f0 |
| Condition dropout | a value marked missing has no effect on the output |
| Tiny autoencoder, with discriminators | mel loss drops by > 20 % in 12 steps |
| Gradient reversal | a linear probe on r reads an attribute much less well with the adversary than without (attribute carried as a condition-dropout backup channel) |
| Singer encoder | the contrastive loss separates synthetic singers |
| Vocoder benchmark | zero error for identity resynthesis; detects a 3 % pitch error (> 30 cents) |

## Not done — needs data and compute

- **No trained weights.** The autoencoder and vocoder need training on AI Hub, VocalSet and own recordings under the
  commercial profile (tens of GPU-hours or more).
- **The vocoder benchmark on breathy, rough and falsetto *Korean singing* has not been run.** The harness exists and
  was exercised on synthetic data only.
- Flow-matching acoustic model: deferred, as the brief allows.
- `c` re-encoding consistency is evaluated, not trained: the DSP curves are not differentiable. Learned heads (M3)
  could make it trainable.
