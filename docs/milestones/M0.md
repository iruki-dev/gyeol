# M0 — Skeleton

## Delivered

- **Package layout** as in the v2 brief (`core`, `io`, `frontend`, `pitch`, `attributes`, `encoders`, `decoder`,
  `align`, `explain`, `demo`, `coach`, `discover`, `data`, `train`, `eval`, `store`, `dsp`, `context`, `verification`).
  Packages owned by later milestones contain only a docstring naming that milestone.
- **`core.FrameGrid`**: one shared time axis (default 44.1 kHz, hop 512 ≈ 86 frames/s, centred frames). Every
  container validates its arrays against its grid, and combining different grids raises `GridMismatchError`.
- **`core.Result` / `Status`**: explicit `ok` / `unreliable` / `failed` / `unavailable` with a reason, never silent defaults.
- **Typed containers**: `Recording`, `AttributeCurve(s)`, `Event`, `Representation`, `Explanation`, `ExplanationItem`, `Span`.
- **Licensing** (`core.license`):
  - `LicenseTag`, `Profile`, and a registry of the assets named in the brief. Every entry is marked
    `verified=False`, because none has been re-checked upstream yet.
  - `require_allowed` refuses anything that is not commercially usable under the commercial profile, and prints the
    AI Hub conditions.
  - The license gate is enforced in `data.open_manifest` and `train.load_checkpoint`/`load_third_party`.
    Checkpoints embed their effective tag (the most restrictive tag among their sources), the source list and the
    config hash.
- **Consent** (`core.consent`):
  - `Provenance`, `Purpose`, `ConsentToken` and `SingerVector`.
  - `ConsentedVoice` cannot be constructed directly. It can only be created from a USER singer vector, the user's
    own recording and a token carrying `voice_synthesis`.
  - `require_consented_voice` is the runtime guard for renderers.
- **Store** (`store`):
  - Per-purpose consent flags with history, and token verification.
  - A feature store that requires `storage` consent.
  - Raw-audio retention, defaulting to `delete_after_extraction`.
  - `delete_user`, which removes all of a user's files and keeps a non-biometric deletion log.
- **Verification toolkit** ported from v0.1: stats (ICC/Bland–Altman/SEM/MDC/EER/TOST/Holm), the degrade grid,
  `operating_threshold` and invariance reports.
- **CLI**: `gyeol licenses`, and `gyeol fetch <name>`, which shows the license, refuses per profile and requires a
  typed `yes` or `--yes`. Nothing is downloaded automatically.
- **CI**: ruff + pytest on CPU (`.github/workflows/ci.yml`).

## Deviations to review

- A fourth consent purpose, `voice_synthesis`, was added next to `analysis` / `training` / `storage`, so that consent
  to analysis never implies consent to rendering the user's voice.
- No registry entry has a download URL yet. `gyeol fetch` therefore prints manual-download instructions until URLs
  and checksums are verified and added.

## Example

```bash
gyeol licenses --profile commercial
gyeol fetch gtsinger            # refused under the commercial profile
```
